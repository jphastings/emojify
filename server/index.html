Emojify

Pick the most relevant emoji for a small length of text.

or try

Run your own

$ docker run -p 8080:8080 ghcr.io/jphastings/emojify

Install locally

$ brew install jphastings/tools/emojify$ echo "happy birthday!" | emojify🥳

Not on Homebrew? go install github.com/jphastings/emojify/cmd/emojify@latest

XRPC endpoint

GET /xrpc/me.byjp.emojify.suggestEmoji?text=Awesome&limit=1
